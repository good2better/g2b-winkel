📖 Stap-voor-stap: gratis Gmail-verzending instellen (éénmalig, ±10 min)
  1. Ga naar script.google.com, log in met je Google-account.
  2. Klik + Nieuw project, wis de voorbeeldcode en plak dit script (klik 📋): 
    function doPost(e){
  var d=JSON.parse(e.postData.contents);
  GmailApp.sendEmail(d.to, d.subject, '', {htmlBody:d.body, name:d.naam||'G2B'});
  return ContentService.createTextOutput('ok');
}
  3. Klik Implementeren → Nieuwe implementatie → type Web-app → Uitvoeren als: Ik · Toegang: Iedereen → Implementeren (1× toestemming geven via "Geavanceerd" → "Ga naar …" → "Toestaan").
  4. Kopieer de web-app-URL (eindigt op /exec), plak hierboven → OPSLAGEN. Mails gaan nu via je eigen Gmail (limiet ±100/dag).
Blijft alleen in jouw browser — nooit op de site. Deze instellingen deelt deze tool met de Mail-Fabriek.
