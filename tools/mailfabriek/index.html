📖 Stap-voor-stap: gratis Gmail-verzending instellen (éénmalig, ±10 min)
  1. Ga naar script.google.com en log in met je Google-account (je Gmail-account).
  2. Klik + Nieuw project. Wis alle voorbeeldcode in het venster.
  3. Plak dit script (klik op 📋 om te kopieren):
    function doPost(e){
  var d=JSON.parse(e.postData.contents);
  GmailApp.sendEmail(d.to, d.subject, '', {htmlBody:d.body, name:d.naam||'G2B'});
  return ContentService.createTextOutput('ok');
}
  4. Klik rechtsboven Implementeren → Nieuwe implementatie.
  5. Kies bij "Type selecteren": Web-app.
    Uitvoeren als: Ik · Toegang: Iedereen → klik Implementeren.
  6. Eerste keer: Google vraagt toestemming → kies je account → "Geavanceerd" → "Ga naar …" → Toestaan. (Veilig: het script draait op jóuw account en mag alleen mail sturen namens jou.)
  7. Kopieer de web-app-URL (eindigt op /exec) en plak hem hierboven → klik OPSLAGEN. Klaar — mails gaan nu via je eigen Gmail.
Let op: gratis Gmail kan ±100 mails per dag versturen — ruim voldoende voor normale lead-lijsten.
Deze gegevens blijven alleen in jouw browser opgeslagen — nooit op de site.
