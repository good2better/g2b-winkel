De techniek erachter (eigen uitvindingen)

🎚 Mixer & Master-engine

Eigen prio-mixbus: kick duckt sub/grit/akk automatisch, per-laag leveling en gain-staging — het "gehoord" van de tools.

🧠 GIO-commando-brein

Parser die mensentaal ("meer club, minder sprong") omzet in echte engine-parameters — fuzzy, snel.

🎲 Dice-generatoren

Deterministische dobbel-engines met stijl-lering (leert uit .mid/audio-drops) — oneindige variatie, eigen smaak.

📡 Fabriek-oog monitor

Lokale agent die pipelines scant en dagelijkse acties oplevert — zelfde truc als de acquisitie-agent.

🧩 Client-side alles

Web Audio API + localStorage + WASM: apps werken offline, nul server-kosten, onmogelijk te lekken.

🔁 Web↔PC sync

.G2B projectbestanden + C++ DPF-plugins: dezelfde engine in browser én desktop-DAW.
